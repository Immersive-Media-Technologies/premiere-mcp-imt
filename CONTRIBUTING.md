# Contributing

Bug reports and workflow ideas are welcome as
[GitHub issues](https://github.com/Immersive-Media-Technologies/premiere-mcp-imt/issues). Include the
Premiere version and UI language, the OS, the client (Claude Desktop, Cursor …), the tool call and
the error text. `premiere-mcp-imt --doctor --json` prints a local, privacy-safe check you can attach.

Pull requests: keep them focused, run `npm run check` (lint, build, tests — no Premiere needed), and
read [`AGENTS.md`](AGENTS.md) for the layout and the rules. By contributing you agree that your
contribution is licensed under this repository's [license](LICENSE).
